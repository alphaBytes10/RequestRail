## Code of Conduct
This project and everyone participating in it is governed by the [RequestRail Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.

## I Have a Question
If you have a question, please start a discussion on the GitHub Discussions page or open an Issue with the `question` label.

## I Want To Contribute

### Reporting Bugs
Bugs are tracked as GitHub issues. Provide as much context as possible, including:
* Rust version (`rustc --version`)
* OS version
* Steps to reproduce the issue

### Suggesting Enhancements
Enhancement suggestions are tracked as GitHub issues. When creating an enhancement issue, please clearly describe the feature or change you want and why it is needed.

### Your First Code Contribution
1. Fork the repo and create your branch from `main`.
2. Run tests via `cargo test`.
3. Format your code with `cargo fmt`.
4. Run clippy via `cargo clippy`.
5. Issue a pull request!
